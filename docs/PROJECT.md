# NEtzplan

## Purpose
Webapp zum Erstellen und Berechnen von Netzplänen (Vorgangsknotennetz) nach DIN 69900:
Vorwärts-/Rückwärtsrechnung, Pufferzeiten, kritischer Pfad, grafische Darstellung mit
Drag & Drop, Import/Export.
